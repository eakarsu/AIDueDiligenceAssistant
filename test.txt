To test the extra features with frontend buttons, you need to start both the backend and frontend servers.

  1. Start the Backend Server:

  cd /Users/erolakarsu/projects/AIDueDiligenceAssistant/backend
  npm install   # if not done already
  npm start     # or node server.js

  2. Start the Frontend Server (in a new terminal):

  cd /Users/erolakarsu/projects/AIDueDiligenceAssistant/frontend
  npm install   # if not done already
  npm start

  3. Open Browser:

  Go to http://localhost:3000

  4. Test Each Feature:

  1. Click "+ Add [Item]" button to create new record
